### 🎯 Project: Class Routine Generator
**Automated University Class Schedule Management System**

#### 📄 Project Description

**Currently deployed at Gopalganj Science and Technology University** — Class Routine Generator automates timetabling for academic departments. It solves scheduling conflicts involving teachers, rooms, batches, and course loads.

#### ✨ Key Features

| Feature | Description |
|:--------|:------------|
| **⚡ Constraint-Based Scheduling** | Backtracking algorithm with bin-packing eliminates teacher and room conflicts |
| **📂 Excel Ingestion** | Upload spreadsheets for courses, teachers, and classrooms |
| **🖥️ Interactive Timetable** | Filter by batch, teacher, and room with real-time adjustments |
| **🤖 AI Assistant** | LLM-powered diagnostics for conflict resolution |
| **📄 PDF Export** | Generate publication-ready timetable documents |
