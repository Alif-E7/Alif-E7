# 🧰 Featured Projects

## 🎯 Class Routine

**Automated University Class Schedule Management System**

<div align="center">
  <img src="https://img.shields.io/badge/Status-Currently%20Deploying-f59e0b?logo=rocket" alt="Currently being deployed" />
  <img src="https://img.shields.io/badge/GSTU-Department%20Deployment-blue" alt="Department deployment" />
</div>

Currently being deployed to departments at **Gopalganj Science and Technology University**, Class Routine automates timetabling for academic departments and solves scheduling conflicts involving teachers, rooms, batches, and course loads.

### Key Features

| Feature | Description |
|:--|:--|
| ⚡ **Constraint-Based Scheduling** | Backtracking and bin-packing eliminate teacher and room conflicts |
| 📂 **Excel Ingestion** | Upload courses, teachers, and classroom data |
| 🖥️ **Interactive Timetable** | Filter by batch, teacher, and room |
| 🤖 **AI Assistant** | LLM-powered diagnostics for conflict resolution |
| 📄 **PDF Export** | Generate publication-ready timetable documents |

## 🚀 GSTU Go

**A university super app for the Gopalganj Science and Technology University community**

<div align="center">
  <img src="https://img.shields.io/badge/Status-Active%20Development-0ea5e9?logo=rocket" alt="Under active development" />
  <img src="https://img.shields.io/badge/University%20Authorities-Linked-10b981" alt="University authorities linked" />
</div>

**GSTU Go is under active development** as a unified university super app. University authorities are linked to the platform, which is designed to connect students and the university community with essential services, information, communication, and workflows through one centralized digital experience.

### Planned Platform Capabilities

| Capability | Description |
|:--|:--|
| 🏛️ **University Services** | Centralized access to important university information and services |
| 🔗 **Authority Connectivity** | Digital connection between students and linked university authorities |
| 📢 **Announcements** | Notices, updates, and campus communication |
| 🧩 **Unified Experience** | Multiple university workflows in one super app |
| 🚧 **Active Development** | Features are continuously being designed and improved |
